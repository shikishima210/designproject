# デコラボ POS

稲友祭(2026年10月25日)の模擬店「デコラボ」で使うWebレジです。IDとパスワードでログインして使います。

## できること

- **レジ**: 商品カードをクリックしてお会計に追加(トレカケース / オプション / 物販の章区切り)。現金のみ。お預かり額からおつりを計算
- **割引**: 管理画面で登録した割引(円引き・%引き)を選択、または「その他の値引き」で金額を直接入力
- **売上**: 売上合計・会計数・値引き合計・販売点数、商品別集計、会計履歴、取消、CSV保存
- **管理**(管理者のみ): 商品と価格、割引、ログインアカウントの管理、練習データの消去
- 商品追加・会計確定の効果音(ON/OFF切替あり)

## 使い方

GitHub Pages で公開したページを使います。初回起動時に管理者IDとパスワードを作成してください。

そのままだとデータはその端末のブラウザ内だけに保存されます(画面右上に「この端末のみ」と表示)。複数の端末で使うときは、次の「全端末で共有する」を設定してください。

## 全端末で共有する(Googleスプレッドシート)

商品・割引・アカウント・売上をGoogleスプレッドシートに保存し、接続した全端末で共有します。売上はスプレッドシートの「売上」シートに1会計1行で入るので、そのまま集計にも使えます。

### 1回だけ行う準備(管理者のPCで)

1. Googleドライブで新しいスプレッドシートを作ります(名前は自由、例: デコラボ売上)。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードをすべて消し、このフォルダの `apps-script.gs` の中身をすべて貼り付けます。
4. 9行目の `const KEY = "ここを合言葉に変える";` の合言葉を、推測されにくいものに書き換えて保存します(英数字12文字以上がおすすめ)。
5. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選び、次のように設定して「デプロイ」します。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. Googleアカウントの承認画面が出たら許可します(「このアプリはGoogleで確認されていません」と出たら「詳細」→「(プロジェクト名)に移動」)。
7. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/…/exec`)をコピーします。

### POSをつなぐ

1. 設定済みの端末でPOSを開き、「管理」→「全端末で共有」にURLと合言葉を入れて「接続する」を押します。この端末の商品・割引・アカウント・売上が、空のスプレッドシートにそのまま移ります。
2. 同じ欄の「リンクをコピー」で接続リンクをコピーし、LINEなどでほかの端末に送ります。
3. ほかの端末でそのリンクを開くと、ログイン画面になり、同じIDとパスワードで使えます。

画面右上が「共有中」なら接続できています。通信が切れても会計はでき、「オフライン・未送信◯件」と表示されます。通信が戻ると自動で送信されます。

### 注意

- 接続リンクには合言葉が入っています。スタッフ以外には送らないでください。
- `apps-script.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン: 新バージョン」で更新してください(URLは変わりません)。
- 共有の反映には数秒かかります。

## 引き継ぎファイル

「管理」→「別の端末への引き継ぎ」で、商品・割引・アカウント・売上を1つのファイルに書き出し、別の端末で読み込めます。共有を使わない場合のバックアップや、オフラインの端末どうしの売上の合算に使えます。

## 注意

パスワードはレジ番用の簡易ロックです。ほかのサービスで使っているパスワードは使わないでください。
