# デコラボ POS

稲友祭(2026年10月25日)の模擬店「デコラボ」で使うWebレジです。IDとパスワードでログインして使います。

## できること

- **レジ**: 商品カードをクリックしてお会計に追加(トレカケース / オプション / 物販の章区切り)。現金のみ。お預かり額からおつりを計算
- **割引**: 管理画面で登録した割引(円引き・%引き)を選択、または「その他の値引き」で金額を直接入力
- **売上**: 売上合計・会計数・値引き合計・販売点数、商品別集計、会計履歴、取消、CSV保存
- **管理**(管理者のみ): 商品と価格、割引、ログインアカウントの管理、練習データの消去
- 商品追加・会計確定の効果音(ON/OFF切替あり)

## 使い方

GitHub Pages のリンクを開き、IDとパスワードでログインします。

商品・割引・アカウント・売上は Firebase(Firestore)に保存され、どの端末で開いても同じ内容になります。パーツ印刷リストと同じ仕組みです。

- 他の端末の会計や変更は、すぐに反映されます
- 通信が切れても会計はでき、通信が戻ると自動で送られます
- Firebase の設定(`index.html` の `FIREBASE_CONFIG`)が空のときは、その端末のブラウザ内だけに保存します(画面右上に「この端末のみ」)

## Firebase の準備(1回だけ)

1. https://console.firebase.google.com で「プロジェクトを追加」(例: `decolabo-pos`)。Googleアナリティクスはオフでよい。
2. **Firestore Database** →「データベースを作成」→ 場所は `asia-northeast1`(東京)→ 本番環境モード。
3. Firestore →「ルール」タブに、このフォルダの `firestore.rules` の中身を貼って「公開」。
4. **Authentication** →「始める」→ ログイン方法で **匿名** を有効にする。
5. Authentication →「設定」→「承認済みドメイン」に `shikishima210.github.io` を追加する。
6. プロジェクトの設定(歯車)→ マイアプリ →「ウェブ」(`</>`)でアプリを追加し、表示される `firebaseConfig` を `index.html` の `const FIREBASE_CONFIG = null;` に入れる。

`firebaseConfig` の値は秘密ではありません(ブラウザに必ず届く値です)。守りは `firestore.rules` で行います。

`firebase-db.bundle.js` は `firebase-db.src.js` を esbuild でまとめたものです(作り方はファイル先頭)。

## 注意

パスワードはレジ番用の簡易ロックです。ほかのサービスで使っているパスワードは使わないでください。
