# デコラボ POS

稲友祭(2026年10月25日)の模擬店「デコラボ」で使うWebレジです。IDとパスワードでログインして使います。

## できること

- **レジ**: 商品カードをクリックしてお会計に追加(トレカケース / オプション / 物販の章区切り)。現金のみ。お預かり額からおつりを計算
- **割引**: 管理画面で登録した割引(円引き・%引き)を選択、または「その他の値引き」で金額を直接入力
- **売上**: 売上合計・会計数・値引き合計・販売点数、商品別集計、会計履歴、取消、CSV保存
- **管理**(管理者のみ): 商品と価格、割引、ログインアカウントの管理、練習データの消去
- 商品追加・会計確定の効果音(ON/OFF切替あり)

## 使い方

GitHub Pages のリンクを開き、IDとパスワードでログインします。サーバーは使いません。

### 商品・割引・ログインIDはページに組み込む

1. 管理者の端末で、商品・割引・スタッフのIDを設定します。
2. 「管理」→「設定ファイルを書き出す」でJSONファイルを保存し、Claudeに送ります。
3. その内容を `index.html` の `const PRESET = …;` に組み込んで公開します。

組み込んだあとは、どの端末でリンクを開いても同じ商品・割引・IDで使えます。設定を変えたいときは、もう一度書き出して送ってください(`PRESET.version` を変えると各端末に反映されます)。

### 売上は端末ごとに保存し、閉店後に合算する

売上は会計した端末のブラウザ内に保存されます。端末どうしでリアルタイムには共有されません。

1. 閉店後、各レジで「管理」→「売上を書き出す」を押します。
2. 集計する1台で「売上を読み込む」から全レジのファイルを選びます(同じ会計は二重に数えません)。
3. 「売上」画面で合計を確認し、必要なら「CSVで保存」します。

ブラウザの履歴やサイトデータを消すと、その端末の売上も消えます。シークレットモードでは使わず、営業中もこまめに書き出してください。

## 注意

パスワードはレジ番用の簡易ロックです。ほかのサービスで使っているパスワードは使わないでください。
