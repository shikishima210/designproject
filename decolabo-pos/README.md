# デコラボ POS

稲友祭(2026年10月25日)の模擬店「デコラボ」で使うWebレジです。IDとパスワードでログインして使います。

## できること

- **レジ**: 商品カードをクリックしてお会計に追加(トレカケース / オプション / 物販の章区切り)。現金のみ。お預かり額からおつりを計算
- **割引**: 管理画面で登録した割引(円引き・%引き)を選択、または「その他の値引き」で金額を直接入力
- **売上**: 売上合計・会計数・値引き合計・販売点数、商品別集計、会計履歴、取消、CSV保存
- **管理**(管理者のみ): 商品と価格、割引、ログインアカウントの管理、練習データの消去
- 商品追加・会計確定の効果音(ON/OFF切替あり)

## 使い方

本番では GitHub Pages で公開したページを使います。claude.ai のアカウントがなくても、リンクを開くだけで使えます。

GitHub Pages で使う場合、データ(商品・割引・アカウント・売上)はその端末のブラウザ内に保存されます(画面右上に「この端末のみ」と表示されます)。

- 端末ごとに初期設定(管理者の作成、商品と割引の登録)が必要です
- 売上は端末間で共有されません。レジ端末は1台にするか、閉店後に各端末から「CSVで保存」して合算してください
- ブラウザの履歴やサイトデータを消すと売上も消えます。シークレットモードでは使わないでください。営業中もこまめに「CSVで保存」してください

claude.ai のアーティファクトとして開いた場合は、データが共有保存され、アクセスできる全端末で同じ売上を見られます。

初回起動時に管理者IDとパスワードを作成してください。

## 注意

パスワードはレジ番用の簡易ロックです。ほかのサービスで使っているパスワードは使わないでください。
