# デコラボ POS

稲友祭(2026年10月25日)の模擬店「デコラボ」で使うWebレジです。IDとパスワードでログインして使います。

## できること

- **レジ**: 商品カードをクリックしてお会計に追加(トレカケース / オプション / 物販の章区切り)。現金のみ。お預かり額からおつりを計算
- **割引**: 管理画面で登録した割引(円引き・%引き)を選択、または「その他の値引き」で金額を直接入力
- **売上**: 売上合計・会計数・値引き合計・販売点数、商品別集計、会計履歴、取消、CSV保存
- **管理**(管理者のみ): 商品と価格、割引、ログインアカウントの管理、練習データの消去
- 商品追加・会計確定の効果音(ON/OFF切替あり)

## 使い方

GitHub Pages のリンクを開き、IDとパスワードでログインします。

商品・割引・アカウント・売上はすべてサーバー(Googleスプレッドシート + Apps Script)に保存されます。どの端末でログインしても同じ内容になり、ログインしないと何も読めません。ID・パスワードの確認もサーバー側で行います。

- サーバーに誰もいないときだけ、最初に管理者アカウントを作る画面が出ます
- 通信が切れても会計はでき、画面右上に「オフライン・未送信◯件」と出ます。通信が戻ると自動で送信されます
- 他の端末の変更は5秒ほどで反映されます
- 売上はスプレッドシートの「売上」シートに1会計1行で入ります

## サーバーの設置(1回だけ)

1. Googleドライブで新しいスプレッドシートを作ります(名前は自由、例: デコラボPOS)。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードをすべて消し、このフォルダの `apps-script.gs` の中身をすべて貼り付けて保存します。
4. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選び、次のように設定して「デプロイ」します。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. Googleアカウントの承認画面が出たら許可します(「このアプリはGoogleで確認されていません」と出たら「詳細」→「(プロジェクト名)に移動」)。
6. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/…/exec`)を、`index.html` の `const SERVER_URL = "";` に入れます。

`apps-script.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン: 新バージョン」で更新してください(URLは変わりません)。

`SERVER_URL` が空のときは、データをその端末のブラウザ内だけに保存します(画面右上に「この端末のみ」)。

## 注意

パスワードはレジ番用の簡易ロックです。ほかのサービスで使っているパスワードは使わないでください。
